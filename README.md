# Anusiya T - Portfolio

A modern, responsive portfolio website built with React showcasing my projects, skills, and experience in web development, data science, and artificial intelligence.

## Features

- ✨ Modern and clean design with gradient backgrounds
- 🌓 Dark/Light mode toggle with preference persistence
- 📱 Fully responsive for all devices
- 🎨 Smooth animations and transitions
- 🚀 Fast performance
- 📄 Downloadable resume
- 🎯 Interactive skill filtering
- 💼 Project showcase with detailed information
- 📧 Contact form
- 🔝 Back to top button

## Technologies Used

- React 18
- CSS3 (No Tailwind)
- Font Awesome Icons
- Google Fonts (Inter & Fira Code)

## Installation & Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm start
   ```
   The app will open at [http://localhost:3000](http://localhost:3000)

3. **Build for Production**
   ```bash
   npm run build
   ```

## Customization

### Adding Your Photo
Replace the placeholder images in `App.js`:
- Line 213: Hero section image
- Line 238: About section image

### Updating Resume
Replace `public/Anusiya_T_Resume.pdf` with your latest resume.

### Modifying Colors
Edit CSS variables in `App.css` (lines 7-17):
```css
:root {
  --primary-500: #0ea5e9;
  --primary-600: #0284c7;
  /* ... */
}
```
